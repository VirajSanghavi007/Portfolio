\section{Research}
\proj{Publicity \& Research Member, DJS Anveshan (Research Club), DJSCE}{Ongoing}\\[2pt]
\textit{Topic: Failure Modes in Federated Learning for Cross-Institutional Fraud Detection}\\[2pt]
\textit{Status: early stage; problem framing and literature review in progress}

\medskip
\textbf{Problem being studied}
\begin{itemize}
  \item Byzantine-robust aggregators (Krum, FLAME) filter client updates that look unlike the majority. An honest institution with non-IID data can look the same as an attacker, so its valid updates may be discarded.
  \item The global model can then report high aggregate accuracy while failing on that institution's fraud patterns, with no signal at the server.
\end{itemize}

\textbf{Current work}
\begin{itemize}
  \item Refining the problem statement and threat model (e.g.\ two similar international banks and one regional bank in a joint fraud model).
  \item Building a literature map of robust aggregation under heterogeneous data to identify what remains open.
\end{itemize}

\textbf{Planned next steps:} form testable hypotheses, then run federated simulations on public fraud datasets comparing FedAvg, Krum, Median, Trimmed Mean and FLAME using per-client metrics.

\textbf{Keywords:} Federated Learning, Byzantine Robustness, Non-IID Data, Fraud Detection
